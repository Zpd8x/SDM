# SDM 3.1.2 — Media Inspector & Activity Polish

This release polishes the right-side Media Inspector, the Activity Center, and the bottom status bar without changing download-engine behavior.

## Highlights
- Searchable Activity Center with debounced refresh.
- Event icons, severity colors, per-cell tooltips, and improved row density.
- Clearer Media Inspector hierarchy and Quick Actions.
- Selectable filenames and tooltips for long paths, URLs, checksums, and adaptive reasons.
- Semantic status and status-bar metric styling.
