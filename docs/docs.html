SDM v2.0.0 guide

Everything needed to install, configure and troubleshoot the final Windows release.

Installation

Download SDM_v2.0.0_Setup_x64.exe, run it, select optional shortcuts and complete the wizard. The installer places the application under Program Files and preserves user data under %LOCALAPPDATA%\SDM.

The Setup package includes yt-dlp, ffmpeg, ffprobe and ffplay. Do not install these tools separately.

Portable package

Extract the portable ZIP to a writable folder and run SDM.exe. Keep the internal Tools and _internal folders beside the executable.

Browser Capture 2.0

  1. Install SDM using Setup.
  2. Extract the Browser Extension ZIP.
  3. Open chrome://extensions or edge://extensions.
  4. Enable Developer mode and choose Load unpacked.
  5. Select the extracted extension folder.

The Native Host supports persistent requests, direct capture, batch downloads, context actions, page audio and secure site-scoped sessions.

Media Inspector

Use Media Inspector before downloading platform media. It displays available audio/video formats, resolution, codecs, HDR, subtitle tracks, playlist status, live-stream status and DRM restrictions.

Smart Rules

Rules are evaluated from top to bottom, and the first matching rule wins.

Network recovery

SDM classifies the connection as Excellent, Good, Fair, Poor or Offline. Recovery can apply exponential backoff, reconnect, mirror rotation and resume validation using ETag and Last-Modified metadata.

Plugin API v1

Plugins use a validated plugin.json manifest. Invalid or broken plugins are isolated so they cannot prevent SDM from starting. Enable and disable plugins in System Center.

System Center and diagnostics

System Center checks SQLite integrity, Python/runtime details, yt-dlp, ffmpeg, ffprobe, ffplay, Browser Extension and Native Host. Export a JSON report when requesting support.

Troubleshooting

A bundled tool appears missing

Confirm the installed application contains a Tools folder with all four executables. Reinstall using the final Setup package if the folder is incomplete.

The browser extension cannot connect

Confirm SDM was installed using Setup, restart the browser, verify the extension ID and run System Center diagnostics.

A download cannot resume

The server may not support byte ranges or its validator may have changed. SDM safely restarts when resuming could corrupt the file.

Windows shows an unknown publisher warning

The current release is unsigned. Verify the SHA-256 checksum before running it. Code signing can be added to a future distribution pipeline.
