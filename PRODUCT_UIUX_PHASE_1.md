# SDM v2.1.0 — Product UI/UX Phase 1

This phase establishes the new visual foundation for the desktop product.

## Included

- New green SDM visual identity matching the official website.
- Product header with brand mark and System Ready badge.
- Live dashboard metrics: total, active, waiting and completed.
- Reorganized primary and secondary actions.
- Cleaner filter controls and download workspace title bar.
- Updated table density, selection, scrollbars and dark palette.
- Existing download logic and workflows remain unchanged.

## Next phase

- Card-based download rows.
- Search and advanced filters.
- Smooth progress animation and speed graph.
- Modern completion toasts and contextual actions.
