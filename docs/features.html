Complete feature set

Built around speed, reliability and control.

The final architecture combines every engine developed from v1.0 through v2.0.

Download engine

Segmented ranges, resume, pause, restart safety, bandwidth limits, queue concurrency and detailed connection progress.

Adaptive connections

Learns server behavior, caps unsafe connection counts and cautiously recovers after rate limits.

Smart Rules

Match URL, domain, MIME, extension, size, adapter or filename and apply folder, rename, category and start-mode actions.

Network recovery

Excellent-to-offline health states, exponential backoff, reconnect, mirror rotation, ETag and Last-Modified validation.

Browser integration

Capture direct files, ChatGPT downloads, Google Drive links, page audio, secure sessions and batch queues.

Media platform engine

yt-dlp extraction, selected formats, audio-only downloads, subtitles, playlists, live flags and DRM awareness.

Duplicate manager

Stable source identity, completed duplicate protection, interrupted-record reuse and safe copy naming.

Storage intelligence

Content fingerprints, identical-content scans, missing or modified file detection and hard-link replacement.

System Center

Database quick-check, tool discovery, browser health, diagnostic export and Plugin API management.
