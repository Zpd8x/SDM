Privacy policy.

SDM is a local desktop application. This website does not include advertising trackers, analytics SDKs or account registration.

Website data

The static GitHub Pages site may be served through GitHub infrastructure. Standard server logs may be processed by GitHub according to its own policies.

Application data

Download history, settings and diagnostic data stay on the local Windows device unless the user explicitly exports or shares them.

GitHub API

The Download page requests public release metadata from the GitHub API to show the latest version and official assets. No authentication token is collected by this site.

Contact

Use the repository Issues page for project questions and bug reports.
