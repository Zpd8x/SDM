Universal Media Capture

SDM 3.2.0 discovers video, audio, HLS, DASH, images and subtitles from page elements and live network traffic, removes duplicate candidates, and sends selected items to SDM in one batch. Site profiles improve results for popular media and cloud-storage services. DRM-protected streams are not supported.
