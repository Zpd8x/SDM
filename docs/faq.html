SUPPORT

Frequently asked questions.

Answers about installation, bundled tools, browser integration and releases.

Does SDM require yt-dlp or FFmpeg to be installed?

No. The final installer and portable package include yt-dlp, FFmpeg, FFprobe and FFplay inside the application Tools directory.

Does SDM modify the Windows PATH?

No system-wide PATH change is required. SDM resolves its bundled tools from the application directory.

Which Windows versions are supported?

SDM v2.0.0 targets 64-bit Windows 10 and Windows 11.

How does browser capture work?

The Manifest V3 extension communicates with the SDM native host and can send detected media to the desktop application.

Where should I download official builds?

Use the GitHub Releases page or the official Download page on this website.
