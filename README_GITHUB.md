# SDM — Smart Download Manager

SDM v2.0.0 Final is a Windows download manager with segmented transfers, pause/resume, adaptive connections, Browser Capture 2.0, Media Inspector, Smart Rules, network recovery, duplicate intelligence, Plugin API v1 and System Center diagnostics.

## Bundled Windows tools

The official Setup and Portable packages include:

- yt-dlp
- ffmpeg
- ffprobe
- ffplay

No manual PATH configuration is required.

## Website

The official documentation website is stored in `docs/` and deployed through GitHub Pages.

## Build

Run on Windows:

```bat
packaging\windows\build_release.bat
```

## Release packages

Binary releases are published under GitHub Releases rather than committed to the repository.
